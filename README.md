# Kartlı Beşleme · Card Five

Kart oyna, pulunu koy, beşli diziyi tamamla!

Kart oynayarak tahtaya pul koyup beşli dizi kurma. Tahta yerleşimi stüdyoya özgüdür; ♣/♦ valeleri joker, ♠/♥ valeleri pul kaldırır. 100.000 üretilmiş ve doğrulanmış bölüm, 33 dil. Masa Oyunları merkez uygulamasının oyunu; ortak motor: masa-motoru.
